# NeonArc PFP layers v2

Every file is 1000x1000 PNG, transparent, and only contains its own trait.

Folders
- BASE_SKIN: head, neck, shoulders. Unchanged.
- BACKGROUNDS: full-frame backgrounds. Unchanged.
- OUTFITS: clothing only. No hair, no eyes, no face.
- HAIR_STYLES: hair only. 5 styles x 5 colors.
- EYES: eyes and eyebrows only. 5 expressions x 5 colors.
- MOUTH: mouth only. 5 expressions.
- ACCESSORIES: the item only. No avatar.

Stack order: background, base skin, outfit, mouth, eyes, hair, accessory.

Colors
- Hair: obsidian_black, electric_blue, hot_pink, platinum_blonde, neon_green
- Eyes: crimson_red, emerald_green, violet, golden_amber, heterochromia_cyan_pink
