# ChainCrafter 3.0 🎨⚡

**ChainCrafter 3.0** is an interactive, high-performance generative anime PFP studio and NFT layer compositor built with Vite, React, and HTML5 Canvas.

## ✨ Features
- **1000×1000 Live Canvas Engine:** Instant 0ms preloaded layer compositing across 7 custom layer stacks.
- **Precision Fitted Layers:** Calibrated anime base skins, streetwear/techwear outfits, expressive mouth & eye optics, vibrant hair dyes, and cybernetic accessories.
- **ERC-721 Metadata Generation:** Instant export for generative metadata JSON and high-resolution PNG downloads.
- **Dynamic Layer Stack Control:** Toggle individual visibility, preview rarity tiers, and shuffle custom generative recipes.

## 🚀 Getting Started

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
